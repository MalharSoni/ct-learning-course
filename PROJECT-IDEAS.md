# Additional STEM Project Ideas for CT Learning Course

This document contains **16 curated project ideas** beyond the initial 8 core projects, organized by difficulty and domain.

---

## 🚁 Robotics & Autonomous Systems

### 9. FPV Racing Drone (Advanced, 6-8 weeks)
**Description:** Build and program a racing drone from scratch using ESP32-based flight controller.

**Skills Learned:**
- Flight dynamics and PID tuning
- FPV camera systems and video transmission
- Brushless motor control and ESCs
- Battery management (LiPo safety)
- Telemetry and real-time data processing

**Parts Needed:**
- ESP32 flight controller board
- 4x Brushless motors + ESCs
- FPV camera and video transmitter
- 3D-printed frame
- LiPo battery and charger
- RC transmitter/receiver

**Portfolio Value:** ⭐⭐⭐⭐⭐ (Cutting-edge tech, video demonstrations)

---

### 11. Gesture-Controlled Robot (Intermediate, 4-5 weeks)
**Description:** Control a V5 robot using hand gestures via an accelerometer-equipped glove.

**Skills Learned:**
- Wireless communication (ESP-NOW, Bluetooth)
- Accelerometer data processing and filtering
- Gesture recognition algorithms
- Real-time control systems
- Wearable electronics design

**Parts Needed:**
- V5 drivetrain
- ESP32 for glove controller
- MPU6050 IMU sensor
- Flex sensors (optional)
- 3D-printed glove housing

**Portfolio Value:** ⭐⭐⭐⭐ (Innovative interface, great demo potential)

---

### 12. 3D Mapping Rover (Advanced, 6-8 weeks)
**Description:** Build a robot that creates 3D maps of environments using LIDAR and SLAM algorithms.

**Skills Learned:**
- SLAM (Simultaneous Localization and Mapping)
- Point cloud data processing
- Autonomous navigation
- ROS (Robot Operating System) basics
- Sensor fusion (LIDAR + IMU + odometry)

**Parts Needed:**
- V5 platform or custom drivetrain
- LIDAR sensor (RPLIDAR A1 or similar)
- Raspberry Pi 4 for processing
- IMU sensor
- Battery pack

**Portfolio Value:** ⭐⭐⭐⭐⭐ (Advanced CS/robotics topic, research-level)

## 🏡 IoT & Smart Systems

### 10. Smart Home Automation Hub (Intermediate, 4-5 weeks)
**Description:** Create a centralized control system for lights, sensors, and appliances using MQTT protocol.

**Skills Learned:**
- IoT communication protocols (MQTT, HTTP)
- Mobile app development (Blynk or custom)
- Relay control for AC appliances
- Sensor networks and data aggregation
- Web dashboard creation

**Parts Needed:**
- ESP32 main controller
- Relay modules (4-8 channel)
- Various sensors (temp, motion, light)
- Power supply and AC wiring safety
- Optional: Touchscreen display

**Portfolio Value:** ⭐⭐⭐⭐ (Practical, relatable for parents/admissions)

### 8. IoT Weather Station (Beginner, 2-3 weeks) ⭐ **Already in Core 8**
**Description:** Monitor weather conditions with ESP32 and display data on web dashboard.

**Skills Learned:**
- ESP32 programming
- Sensor integration (temp, humidity, pressure)
- IoT protocols (Wi-Fi, MQTT)
- Data visualization (web dashboard)

**Parts Needed:**

- BME280 sensor (temp/humidity/pressure)

### 15. Automated Greenhouse System (Intermediate, 5-6 weeks)

## 💡 How to Add New Projects

When creating additional projects, ensure they include:

1. **Clear Learning Objectives** - What skills will students gain?
2. **Phased Curriculum** - Break into 4-6 week milestones
3. **Portfolio Deliverables** - CAD files, code, video, documentation
4. **Parts List** - Specific components needed
5. **Difficulty Rating** - Beginner/Intermediate/Advanced
6. **Time Estimate** - Realistic duration
7. **Prerequisites** - Which learning modules should be completed first
