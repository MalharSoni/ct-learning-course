## 📅 2-Month Program Structure

### **Week 1: Research & Design**
- Choose project (BattleBots, Robotic Arm, etc.)
- Research similar designs, define goals
- CAD initial design in Onshape
- Parts list and strategy document

### **Weeks 2-4: Build & Program**
- Construct robot/system using V5 + custom parts
- Program control systems (driver control, autonomous features)
- Test, iterate, improve based on results
- Document build process (photos, engineering notebook)

### **Week 5-6: Testing & Refinement**
- Competition/demo testing (BattleBots tournament, maze challenge, etc.)
- Repair, reinforce, optimize
- Film demo videos
- Peer feedback and presentations

### **Week 6+: Portfolio Creation**
- Professional documentation (PDF write-up)
- GitHub repository with code and CAD files
- 2-3 minute showcase video
- **Parent Demo Night** - students present their work

## 💡 Sample Project Deep-Dive: BattleBots

### **Why BattleBots is the Perfect First Project**

1. **High Engagement** - Students LOVE combat robots
2. **Broad Skill Coverage** - Mechanical, electrical, programming, strategy
3. **Portfolio Gold** - Videos of robot battles are compelling for applications
4. **Iteration-Friendly** - Easy to repair and improve after matches

### **6-Phase Curriculum:**

#### Phase 1: Research & Strategy (Week 1)
- Study weapon types (spinners, wedges, flippers)
- Analyze successful designs
- Define combat approach

#### Phase 2: CAD Design (Week 2-3)
- Full robot assembly in Onshape
- 3D-printable armor design
- Gear ratio calculations

#### Phase 3: Build (Week 3-4)
- Robust drivetrain for pushing power
- Weapon system assembly
- Electronics installation

#### Phase 4: Programming (Week 4-5)
- Driver control code
- Weapon activation logic
- Safety features

#### Phase 5: Competition (Week 5-6)
- Class BattleBots tournament
- Repair and iterate
- Match strategy development

#### Phase 6: Documentation (Week 6+)
- Professional portfolio write-up
- Video editing and showcase
- Parent demo night presentation

### **What Parents Will See:**
- Live BattleBots tournament (exciting!)
- Student's robot in action (video)
- Professional documentation
- Understanding of weapon physics, electronics, strategy
