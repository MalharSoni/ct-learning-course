# CT Learning Course 🤖

A comprehensive STEM learning platform designed for high school students (grades 9-12) to master VEX V5 robotics, CAD design, programming, and work on exciting hands-on projects that build their technical portfolio.

Built with Next.js, TypeScript, Tailwind CSS, and shadcn/ui.

## 🎯 Purpose

This platform addresses the critical question parents ask: **"What's next after competition season?"**

CT Learning Course provides a structured 2-month curriculum between competition seasons, keeping rookie teams engaged with:
- **Progressive skill-building** from safety basics to advanced techniques
- **Portfolio-worthy projects** for college applications
- **Real-world STEM applications** beyond competition robotics
- **Hands-on learning** using V5 parts, 3D printing, and cheap electronics (ESP32 ecosystem)

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Open http://localhost:3002
```

## 📚 Curriculum Structure

### Learning Course Modules

1. **Getting Started** - Intro to STEM, Engineering Design Process
2. **V5 Building Fundamentals** - Safety, Parts, Bracing, Gear Ratios
3. **V5 Build Concepts** - Lifts, Intakes, Drivetrain Types
4. **V5 Advanced Build** - Power Transmission, Structural Design
5. **V5 CAD** - Onshape, VEX CAD, Motion Studies
6. **V5 Competition Code** - Programming, PID, Odometry
7. **V5 Electronics** - Sensors, Wiring, Troubleshooting
8. **V5 Pneumatics** - Components, Design, Use Cases

### 🔨 Projects (Hands-On Portfolio Builders)

#### 1. **BattleBots** (Intermediate, 4-6 weeks) ⭐
Design and build a combat robot using V5 parts and 3D printed armor.
**Skills:** Weapon Systems, Armor Design, Strategy, 3D Printing

#### 2. **Autonomous Line Follower** (Beginner, 2-3 weeks)
Master PID control and sensor-based navigation.
**Skills:** Sensor Programming, PID Control, Autonomous Navigation

#### 3. **Precision Robotic Arm** (Advanced, 6-8 weeks)
Multi-axis arm with inverse kinematics.
**Skills:** Kinematics, Precision Control, End Effector Design

#### 4. **Maze Solving Robot** (Intermediate, 3-4 weeks)
Autonomous navigation using pathfinding algorithms.
**Skills:** Pathfinding, Sensor Fusion, Decision Making

#### 5. **Ball Launcher System** (Intermediate, 4-5 weeks)
Flywheel-based launcher with trajectory calculation.
**Skills:** Projectile Physics, Vision Targeting

#### 6. **Sumo Wrestling Robot** (Beginner, 2-3 weeks)
Optimized for traction and pushing power.
**Skills:** Weight Distribution, Traction Optimization

#### 7. **Color Sorting Machine** (Intermediate, 4-5 weeks)
Automated sorting using vision sensors.
**Skills:** Vision Processing, Automation, Conveyor Systems

#### 8. **IoT Weather Station** (Beginner, 2-3 weeks)
ESP32-based weather monitoring with data visualization.
**Skills:** ESP32 Programming, IoT Protocols, Sensor Integration
