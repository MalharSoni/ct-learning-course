# CT Robotics Off-Season Curriculum
## 2-Month STEM Learning Program (Grades 9-12)

---

## 📚 Program Overview

**Duration:** 2 months (8 weeks)
**Target:** High school students (grades 9-12) with 1-2 robotics projects completed
**Goal:** Build technical portfolio while maintaining robotics skills between competition seasons

---

## 🎯 Learning Modules

### Module 1: Intro to STEM (1 week)
- What is STEM and career opportunities
- Engineering Design Process (EDP)
- Problem-solving and critical thinking
- How to document technical work for portfolios

### Module 2: V5 Building Fundamentals (2 weeks)
**Safety and Common Parts:**
- Safety protocols and shop tour
- V5 tools: wrenches, Allen keys, cutters
- Structural parts: channels, beams, screws, nuts
- Spacers, standoffs, bearings
- Motors (11W vs 5.5W) and cartridges (100, 200, 600 RPM)
- Wheels: traction, omni, mecanum

**Build Fundamentals:**
- Bracing and structural stability
- Degrees of Freedom (DOF) reduction
- Triangle bracing techniques
- Boxing for strength
- Building your first drivetrain

**Gear Ratios and Friction:**
- Understanding input/output gears
- Torque vs speed trade-offs
- Friction management (clearance vs constraint)
- Screw joints for low-friction rotation
- Free spin testing

### Module 3: V5 Build Concepts (2 weeks)
**Lift Mechanisms:**
- 2-Bar lifts
- DR4B (Double Reverse 4-Bar)
- Linear sliders
- Scissor lifts

**Intake Mechanisms:**
- Top roller intakes
- Compression principles
- Deadzone solutions
- Flex wheels vs rubber rollers

**Drivetrain Types:**
- Tank drive
- X-Drive (holonomic)
- Mecanum drive
- Omni-directional configurations

### Module 4: V5 Advanced Building (1 week)
**Power Transmission:**
- Chains and sprockets
- Advanced gearing (compound ratios)
- Belt drives

**Structural Design:**
- Stress distribution
- Weight reduction techniques
- Modular design philosophy
- Rapid iteration and testing

### Module 5: V5 CAD (2 weeks)
**Onshape Fundamentals:**
- Account setup and interface
- Sketching basics
- Features and extrusions
- Creating assemblies
- Mates and constraints

**VEX-Specific CAD:**
- VEX part library
- CAD your drivetrain
- CAD a 2-Bar wedge
- CAD a DR4B
- CAD a top roller intake

**Advanced CAD:**
- Motion studies
- Interference detection
- Full robot design

### Module 6: V5 Programming (2 weeks)
**Programming Basics:**
- Introduction to programming concepts
- VEXcode environment
- Variables and data types
- Functions and methods

**Robot Control:**
- Motor control commands
- Sensors and input (vision, optical, distance)
- Driver control setup (tank vs arcade)
- Autonomous programming basics

**Advanced Programming:**
- PID control loops
- Odometry and position tracking
- Pure pursuit pathfollowing
- LemLib and advanced libraries

### Module 7: V5 Electronics (1 week)
**Electronics Fundamentals:**
- V5 Brain and ports
- Battery management and charging
- Radio and controller pairing
- Cable management and wiring best practices

**Advanced Sensors:**
- Inertial Sensor (IMU) for orientation
- Vision Sensor for object detection
- Optical Sensor for color/proximity
- Rotation Sensor for tracking
- Distance Sensor for ranging

**Troubleshooting:**
- Common electronics issues
- Using diagnostics tools
- Motor troubleshooting

### Module 8: V5 Pneumatics (1 week)
**Pneumatics Basics:**
- What are pneumatics and when to use them
- Pneumatic components (cylinders, solenoids, reservoir)
- Air reservoir and pump
- Solenoid valve control

**Pneumatic Design:**
- Single vs double acting cylinders
- Tubing and fittings
- Cylinder mounting techniques
- Use cases in competition

## 🔨 Hands-On Projects (Choose 1-2)

### Project 1: BattleBots Combat Robot ⭐
**Difficulty:** Intermediate
**Duration:** 4-6 weeks
**Description:** Design and build a combat robot using V5 parts and 3D-printed armor

**Skills:** Weapon systems, defensive strategies, 3D printing, competition tactics

**Project Phases:**
1. **Week 1: Research & Strategy**
   - Research weapon types (spinners, wedges, flippers, hammers)
   - Analyze successful BattleBots designs
   - Define combat approach and strategy
   - Create initial sketches

2. **Week 2-3: CAD Design**
   - Full robot assembly in Onshape
   - Design 3D-printable armor
   - Calculate gear ratios for weapon
   - Weight calculation

3. **Week 3-4: Build & Assembly**
   - Build robust drivetrain
   - Assemble weapon system
   - Install electronics
   - Attach armor

4. **Week 4-5: Programming**
   - Driver control code
   - Weapon activation logic
   - Safety features

5. **Week 5-6: Testing & Competition**
   - Practice driving
   - Class BattleBots tournament
   - Repair and iterate

6. **Week 6+: Documentation**
   - Portfolio write-up (3-5 pages)
   - Demo video (2-3 minutes)
   - GitHub repository with code/CAD
   - Presentation for showcase night

## 📅 Typical 2-Month Schedule

### Weeks 1-2: Learning Foundation
- Complete Modules 1-2 (STEM Intro, V5 Fundamentals)
- Choose project
- Begin project research phase

### Weeks 3-4: Skill Building
- Complete Modules 3-5 (Build Concepts, Advanced Building, CAD)
- CAD design for project
- Begin physical build

### Weeks 5-6: Programming & Electronics
- Complete Modules 6-7 (Programming, Electronics)
- Program robot/system
- Test and iterate

### Weeks 7-8: Competition & Documentation
- Complete Module 8 (Pneumatics, if applicable)
- Project competition/demo
- Create portfolio documentation
- Prepare showcase presentation

## 🎓 Portfolio Deliverables (Per Project)

Each student will complete:
1. **Engineering Notebook** - Research, design process, iterations
2. **CAD Files** - Onshape assembly and 3D-printable parts
3. **Code Repository** - GitHub with documented, working code
4. **Technical Write-Up** - 3-5 page professional document
5. **Demo Video** - 2-3 minute showcase video
6. **Presentation** - 5-minute talk at parent showcase night

## 🆚 How This Differs from Competition Training

| **Aspect** | **Competition Focus** | **Off-Season Curriculum** |
|------------|----------------------|---------------------------|
| **Goal** | Win tournaments | Build technical portfolio |
| **Timeline** | Intense 3-4 months | Steady 2 months |
| **Output** | One competition robot | 1-2 portfolio projects |
| **Skills** | VEX game-specific | Transferable (CAD, IoT, 3D printing) |
| **College Value** | Tournament placement | Application materials + demos |
| **Stress Level** | High pressure | Self-paced learning |

**Both are valuable** - this curriculum keeps skills sharp while building individual portfolios.
